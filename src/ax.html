APPENDIX附录

速查手册

写代码时随手翻的几页：常用 API、事件接口与触发顺序、Canvas 重建流程、常见问题、术语表和快捷键。所有 API 名称都在本书锁定的版本（Unity 2022.3.62f3、com.unity.ugui 1.0.0、com.unity.textmeshpro 3.0.7）的源码或程序集中核对过。

A.1 常用 API 速查

RectTransform（第 3 章）

成员说明
anchorMin / anchorMax锚点，0～1，相对父节点矩形。两者相等 = 固定尺寸；不等 = 随父节点拉伸
pivot轴心，0～1，旋转缩放的中心，也是 anchoredPosition 的参考点
anchoredPosition / anchoredPosition3D轴心相对锚点（参考点）的偏移
sizeDelta自身尺寸减去锚点框尺寸；锚点重合时就是宽高
offsetMin / offsetMax左下角 / 右上角相对锚点框的偏移（拉伸时的四边留白）
rect本地坐标系下的实际矩形（只读）；布局刚改完时可能是旧值
SetSizeWithCurrentAnchors(axis, size)不改锚点，直接把某个方向的尺寸设成 size
SetInsetAndSizeFromParentEdge(edge, inset, size)贴着父节点某条边、留 inset、尺寸为 size（会改锚点）
GetWorldCorners(Vector3[4]) / GetLocalCorners四个角的世界 / 本地坐标，顺序为左下、左上、右上、右下
ForceUpdateRectTransforms()立即刷新 rect（不触发布局组）

RectTransformUtility（第 3、11 章）

方法说明
ScreenPointToLocalPointInRectangle(rect, screen, cam, out local)屏幕坐标 → 某个 RectTransform 的本地坐标。Overlay 画布 cam 传 null
ScreenPointToWorldPointInRectangle(rect, screen, cam, out world)屏幕坐标 → 该矩形平面上的世界坐标
RectangleContainsScreenPoint(rect, screen, cam)屏幕点是否落在矩形内（GraphicRaycaster 就用它）
WorldToScreenPoint(cam, world)世界坐标 → 屏幕坐标
CalculateRelativeRectTransformBounds(root, child)child 在 root 坐标系下的包围盒
FlipLayoutOnAxis / PixelAdjustPoint沿轴镜像布局 / 把点对齐到像素

接口方法何时触发

IPointerDownHandler / IPointerUpHandlerOnPointerDown / OnPointerUp按下 / 抬起（抬起发给按下时的那个物体）
IPointerClickHandlerOnPointerClick在同一个物体上按下并抬起，且没有被拖拽取消

IBeginDragHandler / IDragHandler / IEndDragHandlerOnBeginDrag / OnDrag / OnEndDrag移动超过阈值开始拖拽 / 拖拽中每次移动 / 松开
IDropHandlerOnDrop拖拽松开时，发给指针下的物体
IScrollHandlerOnScroll滚轮
ISelectHandler / IDeselectHandler / IUpdateSelectedHandlerOnSelect / OnDeselect / OnUpdateSelected成为 / 不再是当前选中物体；选中期间每帧
IMoveHandler / ISubmitHandler / ICancelHandlerOnMove / OnSubmit / OnCancel方向键/摇杆导航、确认键、取消键（发给当前选中物体）

StandaloneInputModule 每帧的处理顺序（摘自 StandaloneInputModule.Process / ProcessMouseEvent），以及一次“按下—拖动—松开”的完整事件序列：

阶段发出的事件（按顺序）
每帧开始UpdateSelected → 当前选中物体
按下的那一帧（选中变化时）Deselect → PointerDown（沿父节点找第一个处理者）→ 记录点击处理者 → InitializePotentialDrag（若有拖拽处理者）；Selectable 在 OnPointerDown 里调用 Select → Select
移动PointerExit / PointerEnter（悬停目标变化时）、PointerMove
首次超过拖拽阈值BeginDrag → （按下物体与拖拽物体不同则）PointerUp 发给按下物体并取消点击 → Drag
拖拽中Drag（每次移动）
松开的那一帧PointerUp → PointerClick（仍可点击时）→ Drop（拖拽中）→ EndDrag（拖拽中）→ 重新计算 Exit / Enter
滚轮Scroll（沿父节点找处理者）
最后（sendNavigationEvents）Move / Submit / Cancel → 当前选中物体

A.3 Canvas 重建流程

改了什么标脏说明
color（Graphic.color）Vertices颜色存在顶点里
Image.spriteVertices（+ Material、Layout，视情况）SetAllDirty，但贴图相同则跳过材质、尺寸相同则跳过布局（m_SkipMaterialUpdate / m_SkipLayoutUpdate）
materialMaterial换材质只标脏材质
TMP 文字内容Vertices + Layout赋相同字符串时跳过
RectTransform 尺寸Vertices（+ 父布局）OnRectTransformDimensionsChange 触发
位置 / 旋转 / 缩放不标脏不重建网格，但所在 Canvas 要重新合批
OnEnable（SetActive(true)）全部SetAllDirty
Animator 写入属性全部OnDidApplyAnimationProperties → SetAllDirty
CanvasGroup.alpha / CrossFadeAlpha不标脏作用在 CanvasRenderer 的继承透明度上

A.4 常见问题 FAQ

问题答
按钮点了没反应？按第 21 章的流程图查；最常见的是被透明图片挡住，用射线调试器看命中列表
新建的 UI 在 Game 视图里看不到？检查是否在 Canvas 下、Camera 模式画布是否指定了相机、父级 CanvasGroup 的 alpha
界面在不同分辨率下错位？Canvas Scaler 选 Scale With Screen Size；元素按“贴哪条边”设锚点；比例差太多时用第 19 章的布局切换
刘海挡住了按钮？用 SafeAreaPanel，Device Simulator 测试；背景延伸进刘海、内容留在安全区内
中文显示成方块？字体资源里没有这些字：用动态字体或把字符集补全，配置 Fallback（第 5 章）
文字放大后发糊？用 TextMeshPro（SDF）代替旧版 Text；World Space 下旧版 Text 要调 dynamicPixelsPerUnit
Layout Group 改了子物体尺寸没效果？父布局组开了 Child Controls Size 时，子物体尺寸由它决定；用 LayoutElement 指定首选尺寸（第 10 章）
刚改完内容读 rect 是旧值？调用 LayoutRebuilder.ForceRebuildLayoutImmediate 或等下一帧
ScrollRect 设置 normalizedPosition 不生效？Content 尺寸还没更新；先强制重建布局再设
粒子特效显示在 UI 下面？Overlay 画布永远在最上；改用 Camera 模式，用 sortingOrder 让粒子夹在两层画布之间（第 19 章）
Mask 和 RectMask2D 用哪个？矩形裁剪优先 RectMask2D；非矩形只能 Mask；很多并排的裁剪区两种都测（第 20 章）
界面静止时 CPU 仍然高？有元素每帧被标脏：用 RebuildWatcher 找出来（第 20 章）
隐藏界面用哪种方法？频繁开关用 CanvasGroup 或 Canvas.enabled；很少打开的用 SetActive；不要长期移出屏幕（第 20 章实测）
Batch 数很高？重叠元素交替使用不同贴图 / 材质；打图集，调整层级顺序；用 Profiler 的 UI 模块看打断原因
点击 UI 时角色也跟着移动了？处理场景点击前判断 EventSystem.current.IsPointerOverGameObject()
循环里 AddListener 所有按钮都传了同一个值？闭包捕获了循环变量，先拷贝到局部变量（第 6 章）
InputSystem 包装好之后 UI 点不了？把 StandaloneInputModule 换成 InputSystemUIInputModule，或 Active Input Handling 选 Both
World Space 画布点不到？指定 Event Camera；检查 GraphicRaycaster 和 Blocking Objects（第 19 章）
